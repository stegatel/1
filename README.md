# TechAccessory - Інтернет-магазин мобільних аксесуарів

Повноцінний інтернет-магазин з CRM-панеллю для управління товарами, замовленнями та складом.

## 📁 Структура проекту

```
/workspace/
├── index.html              # Головна сторінка магазину (668 рядків)
├── css/
│   ├── style.css           # Стилі сайту (1448 рядків)
│   └── admin.css           # Стилі адмін-панелі
├── js/
│   ├── main.js             # JavaScript логіка магазину (1067 рядків)
│   └── admin.js            # JavaScript логіка CRM (796 рядків)
└── admin/
    ├── login.html          # Сторінка входу в адмінку
    ├── dashboard.html      # CRM панель керування (554 рядки)
    ├── js/
    │   └── login.js        # Логіка авторизації
    └── images/             # Зображення для адмінки
```

**Всього: 3500+ рядків коду**

## 🛒 Функціонал магазину

### Каталог товарів
- **16 товарів** у 7 категоріях:
  - Чохли (Cases)
  - Зарядні пристрої (Chargers)
  - Кабелі (Cables)
  - Навушники (Audio)
  - Захисне скло (Protection)
  - Тримачі (Holders)
  - PowerBank

### Можливості
- ✅ Пошук за назвою, артикулом, штрихкодом
- ✅ Фільтрація за ціною та наявністю
- ✅ Сортування (ціна, назва, новинки)
- ✅ Кошик з промокодами (CASE20=-20%, NEW10=-10%, SALE15=-15%)
- ✅ Обране (Wishlist)
- ✅ Порівняння товарів (до 3)
- ✅ Оформлення замовлення (3 кроки)
- ✅ Маска телефону +38 (XX) XXX-XX-XX
- ✅ Профіль користувача з історією замовлень
- ✅ Інформаційні модальні вікна (Про нас, Доставка, Гарантія, Повернення)

### Товари мають:
- Артикули (SKU)
- Штрихкоди (EAN-13)
- Фото (placeholder зображення)
- Рейтинги та відгуки
- Бейджі (Новинка, Акція, Хіт)
- Старі ціни для знижок
- Індикатори наявності

## 🚀 Запуск

### Магазин
1. Відкрийте `index.html` у браузері
2. Додавайте товари до кошика
3. Оформлюйте замовлення

### Адмін-панель
1. Відкрийте `admin/login.html`
2. Введіть логін: `admin`
3. Введіть парль: `admin123`
4. Керуйте магазином!

## 💾 Зберігання даних

Всі дані зберігаються в `localStorage` браузера:
- `products` - товари
- `cart` - кошик
- `wishlist` - обране
- `compare` - порівняння
- `orders` - замовлення
- `profile` - профіль користувача

## 📱 Промокоди

- `CASE20` - знижка 20%
- `NEW10` - знижка 10%
- `SALE15` - знижка 15%

## 🔧 Технічні деталі
